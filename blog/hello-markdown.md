# 博客，从 Markdown 开始

这个空间现在可以直接从 Markdown 文件生成文章了。

## 写下你的第一篇文章

在根目录的 `blog/` 下新建一个 `.md` 文件，也可以用 `imzako new` 命令生成：

```text
imzako new "文章名称" --tags "技术 笔记"
```

文件开头的 front-matter 决定标题、日期和分类：

```markdown
---
title: 文章名称
date: 2026-09-12T21:30:00+08:00
tags: 技术 笔记
draft: false
---
```

`draft` 设为 `true`、`yes` 或 `1` 时，文件仍可在 `blog/` 中继续编辑，但不会出现在公开列表或正文接口。

- `title` 是文章标题；没写时回退到第一个一级标题，再回退到文件名。
- `date` 用于排序与展示；没写时回退到文件修改时间。
- `tags` 用空格分隔，会与所在子目录一起成为这篇文章的分类。
- `draft` 可在文章完成前暂停对外发布。
- 保存文件后，列表和已经打开的正文会自动更新。
- 删除文件会让文章下线；重命名文件会更改文章地址。
- 可以使用子目录组织文章，首页依然只展示最近更新的 10 篇。
