# 博客，从 Markdown 开始

这个空间现在可以直接从 Markdown 文件生成文章了。

## 写下你的第一篇文章

在根目录的 `blog/` 下新建一个 `.md` 文件。第一行一级标题会成为文章标题，正文会自动转换为 HTML。

- 保存文件后，列表和已经打开的正文会自动更新。
- 删除文件会让文章下线；重命名文件会更改文章地址。
- 可以使用子目录组织文章，首页依然只展示最近更新的 10 篇。

## 一段代码

```js
const message = 'Hello, Markdown!'
console.log(message)
```

> 慢慢记录，持续创造。

| 内容 | 支持 |
| --- | --- |
| 标题、列表、引用 | 是 |
| 代码块、表格、链接 | 是 |
| 本地图片 | 是 |

保存 Markdown，文字便会在这里自动更新；连接恢复后，也会补齐离线期间的修改。
